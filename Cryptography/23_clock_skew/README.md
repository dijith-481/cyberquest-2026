### Challenge Name

Clock Skew

### Challenge Description

The east stairwell door has run on a rotating code since the power event, and has not behaved since either. It is not broken. It is doing exactly what it was built to do, which maintenance has confirmed in writing.

Maintenance kept a clipboard log of everything the door accepted. The log is attached, because the door's own memory was considered unreliable.
