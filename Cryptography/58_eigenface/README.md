### Challenge Description

The east lobby's face scanner has been misreading the same visitor for six
weeks. Facilities would like it noted that the scanner is working exactly as
installed.

A reconciliation dump went out with the incident paperwork. Compliance reviewed
it, and their assessment is that the samples cannot be used to recover anything
without an enrolment you already hold. Compliance is usually right.

One of the sealed review notes is in the same bundle.
