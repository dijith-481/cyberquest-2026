### Challenge Description

The pre-merger skill matrix was imported into the new HR system in one batch. Every import timestamp came out between 1984 and 1989. The vendor blamed the source system. The source system was a spreadsheet written in 2024. Nobody has asked a follow-up question since.

The archive was then exported in pieces and reassembled by hand, on a machine that "has never lost anything, technically." The candidate imports that never reached a branch are still in there — and one of them was sent to cold storage during the reassembly. The cold storage index was not.
