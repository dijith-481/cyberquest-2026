# The Corridor That Remembers

### Challenge Name

The Corridor That Remembers

### Challenge Description

A psychology student built a digital "memory palace" and archived every
experiment session. Their own notes describe the problem plainly:

> "Whenever I'm uncertain, I choose the path I chose before.
> Eventually I stopped knowing whether I remembered the correct path,
> or simply remembered choosing it."

The archive is the maze. Every familiar-looking thing in it — the obvious
file, the obvious door, the obvious choice — will take you exactly where
you've already been. The way out is to stop trusting what things are called
and start checking what they are.

The maze is self-contained: every link is relative and stays inside wherever
you extract it. Nothing walks around your filesystem.
