### Challenge Description

Facilities ordered a fresh batch of asset tags for the lab printers. The scanner app reports every one of them as damaged, and the vendor ticket queue insists the batch passed QC on their side, which is a sentence Facilities has now read some four hundred times.

The tags are named IMG_001 through IMG_014 and they all look equally wrong.
