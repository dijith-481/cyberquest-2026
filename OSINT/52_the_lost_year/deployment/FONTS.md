The Lost Year — fonts and third-party material

The deployment loads two typefaces from Google Fonts at request time:

- UnifrakturMaguntia  — SIL Open Font License 1.1
  https://fonts.google.com/specimen/UnifrakturMaguntia
- IBM Plex Mono       — SIL Open Font License 1.1 (as "IBM Plex Mono")
  https://fonts.google.com/specimen/IBM+Plex+Mono

Neither font file is redistributed here, so no license text has to be
bundled; the pages carry system fallbacks ("Old English Text MT", Luminari,
and the platform monospace stack) and remain readable if the CDN is
unreachable.

No other third-party material is used. All text, layout and inline SVG
artwork (the favicon, the sword cursor) were written for this challenge.
