# Source artwork and attribution

`Own2.png` is the unmodified source artwork from the CindyJS **Eschers Print
Gallery and the Droste Effect** example. The user selected this reconstruction
and approved the straight view rendered with geometry `(1,0)`.

- Demo: https://cindyjs.org/gallery/main/Droste/
- Source directory: https://github.com/CindyJS/website/tree/master/src/gallery/main/Droste
- Artwork file: https://raw.githubusercontent.com/CindyJS/website/master/src/gallery/main/Droste/Own2.png
- Transform source: https://github.com/CindyJS/website/blob/master/src/gallery/main/Droste/droste.html
- Source page's license link: https://creativecommons.org/licenses/by-sa/4.0/
- Original subject: M. C. Escher, *Print Gallery* (1956).
- Reconstruction research: https://pub.math.leidenuniv.nl/~smitbde/escherdroste/

Credit the CindyJS gallery contributors and the original artwork/reconstruction
creators in the event's artwork credits. This source attribution is retained
with the organizer files; it does not add a clue sheet to the player ZIP.

Dimensions: **1196×1360**. SHA-256:

```text
bed9e3b0dd0fe99b2dc469151b19ad95191797c856134425ac221f94dd98b3b0
```

The NumPy renderer is an independent implementation of the published mapping.
It preserves the source aspect ratio and the demo's offsets rather than
replacing them with the idealized scale-256 approximation. Artwork changes
in the handout are geometric resampling and a maximum one-level change to
the blue channel for the hidden text.
